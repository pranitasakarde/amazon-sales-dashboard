# 📊 Amazon Sales Analytics Dashboard

An interactive **Amazon Sales Analytics Dashboard** built using **Microsoft Power BI** to analyze sales performance, orders, customers, payment methods, discounts, and order status.

## 📌 Dashboard Overview

This dashboard provides a clear and interactive view of Amazon sales data through KPIs, charts, maps, and slicers.

### 📈 Key KPIs

- **Total Sales:** 91.83M
- **Total Orders:** 100K
- **Total Quantity:** 300K
- **Average Order Value:** 918.26
- **Total Shipping Cost:** 740.67K

## 📊 Dashboard Visualizations

The dashboard includes:

- 📈 Sales Trend by Year
- 📊 Sales by Category
- 💳 Sales by Payment Method
- 🌍 Sales by City and Country
- 🏷️ Total Sales by Discount
- 📦 Orders by Order Status
- 🔎 Interactive filters for:
  - Order Date
  - Category
  - City
  - State
  - Order Status
  - Payment Method
